# Smart Home Automation System

A complete IoT-based Smart Home Automation & Security System that allows users and admins to monitor, control, and automate household devices through a mobile application. The system integrates lighting, security, water management, door locks, fan control, and alert notifications into a single smart platform.

## Overview

This project aims to provide comfort, automation, energy efficiency, and enhanced security for homes.
It uses sensors, actuators, and a mobile interface to perform tasks like:

Turning lights ON/OFF automatically or manually

Detecting motion and triggering alarms

Managing water tank levels

Controlling door locks remotely

Activating fans based on temperature

Sending real-time notifications to the user

Admins have additional control to view users, manage system access, and monitor critical statuses.

## Features

#### Login & Profile Management
- users can register, edit profiles, and personalize app modes (Light/Dark).

#### Lighting Control

- Manual ON/OFF from mobile

- Automatic activation based on motion after 6 PM

- Manual switch override

#### Security System

- Motion detection alerts

- Laser-based perimeter detection (with buzzer)

- Security mode ON/OFF

- Door lock remote control

- Door open alert & “door left open” reminder

#### Water Tank Automation

- Auto water pumping when level is low

- Auto stop when full

- Manual motor control

- Water level display (Low, Medium, Full)

#### Fan Automation

- Auto ON/OFF based on temperature

- Manual override via mobile or switch

- Temperature monitoring & critical heat alert
